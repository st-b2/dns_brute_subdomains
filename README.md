# DNS Subdomain Brute Forcer

Простой и эффективный инструмент для брутфорса поддоменов с использованием DNS-резолвинга. Написан на Python с использованием библиотеки dnspython.

!!! Однопоточный !!! (пока что :3)
## 📋 Описание

Программа перебирает список возможных имён поддоменов из словаря и проверяет их существование через DNS-запросы типа A. Для каждого найденного поддомена выводится соответствующая запись типа A.
## ✨ Возможности
- 🚀 Быстрый брутфорс поддоменов по словарю
- ⏱️ Настраиваемые таймауты DNS-запросов (timeout: 1.5с, lifetime: 3.0с)
- 🛡️ Корректная обработка типичных ошибок DNS (NXDOMAIN, NoAnswer, Timeout, NoNameservers)
- 📊 Итоговая статистика по найденным поддоменам
- 💡 Простой CLI-интерфейс

## Клонирование репозитория
```bash
git clone https://github.com/st-b2/dns_brute_subdomains.git
cd dns_brute_subdomains
```
## 🚀 Использование
```bash
python brute_domains.py <domain> <wordlist_file>
```

## Формат словаря
Файл со словарём должен содержать по одному поддомену на строку:
```text
www
mail
api
dev
test
admin
```
